# Testing

Commands: npm ci; npm run check; npm test; npm run validate:assets; npm run build; npm run test:browser; npm run spike:network. Browser tests use installed Google Chrome through Playwright, one worker. On another machine install Chrome or configure an available Playwright browser explicitly. Playwright builds a test-mode production bundle and starts the static preview server automatically if port 5173 is free. Do not let an unrelated server occupy the fixed port.

Current milestone: **137 Node tests**, focused GFX-R03 terrain, GFX-R04 Norway/Arizona scenery, GFX-R05 Norway V3 landforms, GFX-R06 Arizona V2 geology, CON-03 construction and complete passenger/save Chrome journeys, strict TypeScript, Blender validation and test builds. GFX-R06 preserves the V1 fingerprint and verifies V2's independent fingerprint, cross sections, flat settlement pads, two feasible long corridors, the 809.081 m bridge and fixed regional/canyon/escarpment/wash views with clean shader console and terrain agreement below 0.001 m.

Core tests cover triangle interpolation/borders/copy isolation, seeded generation/RNG continuation, arc length and distance, graph validity/weighted/reverse/disconnected paths, tangent/grade/horizontal-and-vertical-radius/cusp constraints, continuous vertical profiles, class-specific construction price/speed revalidation, advance braking for slower track, exact terrain boundary crossing with narrow flooded-cell regression, ground/bridge/tunnel quotes, clock frame-rate/speed/pause/debt invariants, 360-day calendar boundaries and vehicle-year eligibility, train edge crossing, save/load with dwell/turnaround, ordered multi-stop loops, full-leg single-track arbitration, blocked-station recovery, sequential schema migration/progress guard, invalid saves/ledger/references/reservations, ID allocation, snapshot isolation, company valuation, multi-train route reporting, all six station classes, atomic station upgrades, storage limits and consist/platform compatibility.

Browser tests exercise all 72 campaign-selected production GLBs and 12 shared PNGs through the actual GLTFLoader/TextureLoader, finite normals/bounds, production 16 km terrain raycasts, multi-car motion, pause/1×/8×, IndexedDB save + browser reload + exact loaded-state comparison, portable download/reimport with malformed-file isolation, alignment/station tools, passenger and freight consist purchase/route assignment, close/far LOD, 1440×900 and 390×844 layouts, console errors, 20k-tree/2k-building/100-train scaling, five V1↔V3 replacements and full disposal. The Arizona V2 study additionally checks 10,500 retained scenery instances, 180 temporary building blockouts, fewer than two million main-pass triangles and the regional, canyon, escarpment, wash, settlement, vegetation, industry and train cameras. Inspection views cover the current steam/coach/freight stock plus the El 1, Di 3B, Di 4 and El 18 locomotives. The passenger QA journey starts with no railway, places two oriented stations on open ground, connects their visible platform ports, buys and assigns a passenger consist, waits for real passenger and mail loading/delivery/revenue/operating cost, reconciles cash, reloads the exact schema-7 save and resumes simulation. A separate commissioned-line journey carries timber into the sawmill and returned lumber to town over the physically simulated route, while checking visible inventory and reconciled freight income. Screenshots are visually reviewed; no test substitutes mocked WebGL for the engine.

Bug found and fixed: initial RAF timestamp can precede setup performance.now(), causing negative clock input and a stopped first frame. The real browser startup/reload test now passes. Terrain query/render mismatch was eliminated by standardizing the same NW→SE triangle split.

Rendering performance tests report sampled measurements rather than asserting universal FPS on unknown hardware. Node geometry/graph timing is not a graphics benchmark. Shader/GLB visual tests prove the current simple materials; future texture/animation imports require their own tests.

QA-001, ECON-003, ECON-004, STATION-002, ART-001, FIN-002 and GFX-001 through GFX-008 are complete. The automatic commissioned preview remains the attractive landing state, while selecting “Start new company” creates the empty railway and empty-industry state used by the player-action gate.

Later system tests: block signals, platform selection, priority scheduling, double track, demand expiry, objective rewards, historical accounting, released save fixtures and general renderer empty states. No architecture redesign is implied by these missing implementations.
